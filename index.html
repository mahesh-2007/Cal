Paste a free Google AI Studio key to enable real photo analysis with Gemini 3.5 Flash-Lite and 3.8 Flash. Free tier: 250 requests/day, no card. Open Google AI Studio →

Without a key the app still works — scans fall back to a built-in 90-food estimator.
How to connect Gemini
  1. Open Google AI Studio and sign in to your Google account.
  2. Choose Create API key and copy the key.
  3. Paste it below, tap Save key, then tap Test.
Your key stays on this device. Gemini features need internet; tracking and offline estimates still work without a key.
Security note: Google's own docs say not to ship keys in client-side code, because anyone can extract them. This app saves the key in local device storage and sends it to Google's API only for analysis. JSON backups do not include the key. For a public deployment, put the call behind a small proxy and restrict the key to the Generative Language API.
